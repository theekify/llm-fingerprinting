# LLM Fingerprinting: Authorship Attribution via Stylometric Analysis

Classifies which open-source LLM generated a given text sample using
stylometric and statistical features — no paid APIs, no semantic/content
features, purely style.

## Status: Phase 1 — Data Generation (in progress)

## Project structure
See `src/` for pipeline scripts, `data/` for generated text and features,
`results/` for trained model outputs and figures.
